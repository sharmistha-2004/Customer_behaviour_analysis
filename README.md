# Customer_behaviour_analysis
Customer behaviour analysis using Python, SQL, and Power BI to identify customer patterns, trends, and insights through data analysis and visualization.

## Project Overview

This project focuses on analyzing customer shopping behaviour using Python, SQL, and Power BI. The goal is to understand customer patterns, purchasing behaviour, and business trends from the available data.

I worked with the dataset to clean and analyze the data, answer business-related questions using SQL, and create an interactive Power BI dashboard to present meaningful insights.

## Tools & Technologies

- Python
- Pandas
- NumPy
- SQL
- MySQL
- Power BI
- DAX
- Data Cleaning
- Data Visualization

## Project Workflow

### 1. Data Cleaning & Preparation – Python

Python was used to:
- Load and explore the dataset
- Check for missing and duplicate values
- Clean and prepare the data
- Perform basic data analysis
- Identify useful customer behaviour patterns

### 2. Data Analysis – SQL

SQL was used to:
- Query customer and sales data
- Analyze customer purchasing behaviour
- Find important business trends
- Calculate useful metrics
- Answer business-related questions from the dataset

### 3. Dashboard – Power BI

Power BI was used to create an interactive dashboard for visualizing the analysis.

The dashboard helps understand:
- Customer behaviour
- Sales and purchasing trends
- Product performance
- Customer segments
- Key business insights

DAX was used to create calculated measures and KPIs for the dashboard.
